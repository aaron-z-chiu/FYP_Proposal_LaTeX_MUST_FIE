This LaTeX template requires the exact **Calibri** font family. However, Calibri is not available by default on Overleaf.

该 LaTeX 模板需要使用完整的 **Calibri** 字体族。然而，Overleaf 默认并不提供 Calibri 字体。

Due to font licensing and redistribution restrictions, the Calibri font files are not included in this repository. Please obtain the required font files from your own legitimate source and place them in this directory using the filenames expected by the template.

由于字体许可及再分发限制，本仓库不包含 Calibri 字体文件。请自行通过合法来源获取所需的字体文件，并按照模板要求的文件名将其放置在此目录中。

The required files are / 需要的文件有 :

- `calibri.ttf`, Regular，正常字体
- `calibrib.ttf`, Bold，粗体
- `calibrii.ttf`, Italic，斜体
- `calibriz.ttf`, Bold Italic，粗斜体
